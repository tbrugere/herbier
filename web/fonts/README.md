# Fonts

Bundled so the app renders offline (`docs/stack.md`). `_base.sass` declares
them with `@font-face`; `scripts/build-web.sh` copies the fonts and licences to `dist/`.

| File | Font | Axes | Subset |
|---|---|---|---|
| `manrope-latin.woff2`, `manrope-latin-ext.woff2` | Manrope (OFL) | wght 400–800 | latin, latin-ext |
| `newsreader-latin.woff2`, `newsreader-latin-ext.woff2` | Newsreader roman (OFL) | opsz 6–72, wght 400–500 | latin, latin-ext |
| `newsreader-italic-latin.woff2`, `newsreader-italic-latin-ext.woff2` | Newsreader italic (OFL) | opsz 6–72, wght 400–500 | latin, latin-ext |
| `material-symbols.woff2` | Material Symbols Outlined (Apache 2.0) | fixed: FILL 0, wght 400, GRAD 0, opsz 24 | the names in `icons.txt` |

The text fonts are the files Google Fonts serves for
`css2?family=Manrope:wght@400..800&family=Newsreader:ital,opsz,wght@0,6..72,400..500;1,6..72,400..500`
(fetched 2026-11-06, Manrope v23, Newsreader v26). The `unicode-range` of each
`@font-face` is the one of that answer. The icon font is regenerated by
`scripts/subset-icons.sh` from `icons.txt`.

Licences: `OFL-Manrope.txt`, `OFL-Newsreader.txt`, `LICENSE-MaterialSymbols.txt`.
